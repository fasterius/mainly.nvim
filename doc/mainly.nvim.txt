 6. KEYMAPS 				                *mainly.keymaps*

 This plugin does not export any key mappings by default (:help
 lua-plugin-keymaps), but exposes Lua functions (|mainly.usage|) and
 user-commands (|mainly.commands|), which you can map yourself. For
 example:
>lua
     local plugin = require("mainly.nvim")
     vim.keymap.set('n', '<localleader>h', plugin.hello)
<

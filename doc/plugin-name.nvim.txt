 6. KEYMAPS 				                *plugin-name.keymaps*

 This plugin does not export any key mappings by default (:help
 lua-plugin-keymaps), but exposes Lua functions (|plugin-name.usage|) and
 user-commands (|plugin-name.commands|), which you can map yourself. For
 example:
>lua
     local plugin = require("plugin_name")
     vim.keymap.set('n', '<localleader>h', plugin.hello)
